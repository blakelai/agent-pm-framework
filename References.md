# Design references

These references describe the underlying products and concepts. The project workflow, document contract and local checks are this framework's own implementation.

- [Obsidian data storage](https://obsidian.md/help/data-storage): local Vault storage.
- [Obsidian Properties](https://obsidian.md/help/properties): editable document metadata.
- [Obsidian file formats](https://obsidian.md/help/file-formats): supported source formats.
- [OpenWiki repository](https://github.com/langchain-ai/openwiki): repository documentation and evidence.
- [Ubiquitous Language](https://martinfowler.com/bliki/UbiquitousLanguage.html): evolving shared terminology within a domain.
- [OKF specification](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md): the v0.2 format used by the local authoring profile and export validator.

The working Vault keeps native agent runtime files. See [OKF profile](90_Agent/OKF-Profile.md) for the boundary between working files, evidence assets and the portable knowledge export.
