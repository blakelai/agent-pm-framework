# Product requirements

Use this Skill with the complete Agent PM Vault. Resolve the Vault root three levels above this file; copying the Skill folder alone does not preserve its dependencies.

Input: BRD versions, SYS/EVD, context glossaries and decisions.

Output: PRD, REQ notes, traceability and unresolved constraints.

Before writing, read [Settings](../../../00_Governance/Settings.md), [Language Policy](../../../90_Agent/Language-Policy.md) and [AGENTS](../../../AGENTS.md). Apply the [Playbook](../../../90_Agent/Playbooks/05-PRD.md). Read [Schema](../../../00_Governance/Schema.md) when changing document properties, and the [baseline/change procedure](../../../00_Governance/Baselines-and-Changes.md) only when a baseline or approval is involved.

Finish independent drafts and checks within scope; record missing information explicitly. The Playbook defines completion. Save an English Run with effective language settings, produced artifacts, source versions, check results and open decisions.
