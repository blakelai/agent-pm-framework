# Material intake and evidence

Use this Skill with the complete Agent PM Vault. Resolve the Vault root three levels above this file; copying the Skill folder alone does not preserve its dependencies.

Input: Raw materials and their permitted analysis scope.

Output: Source notes, EVD claims, extraction/review gaps.

Before writing, read [Settings](../../../00_Governance/Settings.md), [Language Policy](../../../90_Agent/Language-Policy.md) and [AGENTS](../../../AGENTS.md). Apply the [Playbook](../../../90_Agent/Playbooks/01-Intake.md). Read [Schema](../../../00_Governance/Schema.md) when changing document properties, and the [baseline/change procedure](../../../00_Governance/Baselines-and-Changes.md) only when a baseline or approval is involved.

For unclear, missing or conflicting inputs, apply [Evidence and Clarification Policy](../../../90_Agent/Evidence-and-Clarification-Policy.md): ask the user for clarification or relevant material, prohibit unsupported inference and keep dependent work pending. Finish only supported independent drafts and checks. The Playbook defines completion subject to that policy. Save an English Run with effective language settings, produced artifacts, source versions, questions asked, answer provenance, blocked work, check results and open decisions.
